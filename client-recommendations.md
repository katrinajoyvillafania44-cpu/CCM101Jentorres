Cloud Platform Recommendations
Client A – Startup Company

Recommended Platform: Amazon Web Services (AWS)

AWS is a suitable option for a startup because it offers a wide range of cloud services that can grow along with the business. The company can begin with limited resources and increase its capacity as the number of users and applications grows. AWS also provides managed services that reduce the need for maintaining physical servers.

Three useful services:

Amazon EC2 – Used to host the backend of the mobile application.
Amazon S3 – Used to store images, documents, and other files.
AWS Lambda – Allows code to run without requiring the company to manage servers.
Client B – University

Recommended Platform: Microsoft Azure

Microsoft Azure is a strong choice for the university because it already uses Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory. Azure can integrate with these existing systems, making it easier to manage users and migrate services. The university can gradually transfer selected workloads to the cloud while continuing to use familiar Microsoft tools.

Three useful services:

Azure Virtual Machines – Used to host Windows Server-based applications and workloads.
Microsoft Entra ID – Provides identity and access management for users and resources.
Azure Storage – Used for storing files, documents, and backup data.
Client C – AI Research Company

Recommended Platform: Google Cloud Platform (GCP)

Google Cloud is an excellent option for an AI and machine learning research organization. It provides high-performance computing resources and specialized tools for handling artificial intelligence and data-intensive workloads. Its services also support the development, training, and deployment of machine learning models.

Three useful services:

Google Compute Engine – Provides computing resources for demanding workloads.
Google Kubernetes Engine (GKE) – Used to operate containerized AI applications.
Vertex AI – Supports the creation, training, and deployment of AI and machine learning models.
Client D – Global E-Commerce Company

Recommended Platform: Amazon Web Services (AWS)

AWS is a suitable platform for a worldwide e-commerce business because it has a large global infrastructure. Its services can automatically adjust resources when website traffic increases and help maintain application availability. This makes AWS appropriate for online stores that serve customers across multiple countries.

Three useful services:

Amazon EC2 – Used to run e-commerce websites and applications.
Amazon S3 – Used to store product photos, documents, and other digital files.
Elastic Load Balancing – Distributes incoming traffic across multiple servers to improve performance and availability.
Checkpoint 6 – Multi-Cloud Decision Matrix
Business Requirement	Recommended Platform	Justification
Startup Company	AWS	AWS offers flexible and scalable services that can help startups manage expenses while expanding. Services such as EC2, S3, and Lambda support application development and deployment.
Enterprise Organization	AWS	AWS provides a wide range of enterprise-level services, security capabilities, and worldwide infrastructure. EC2, Amazon RDS, and Amazon VPC can be used to create secure and scalable systems.
Microsoft Environment	Azure	Azure is ideal for organizations that already depend on Microsoft technologies. It works closely with Windows Server, Microsoft 365, Active Directory, and other Microsoft solutions.
AI / Machine Learning	GCP	GCP is well suited for artificial intelligence and machine learning because it offers specialized AI tools and services. Vertex AI, BigQuery, and Google Cloud Storage can support data analysis and ML projects.
Kubernetes Deployment	GCP	GCP offers Google Kubernetes Engine (GKE), a managed platform for deploying and operating containerized applications. It provides scalability, automation, and integration with other Google Cloud services.
Global Web Application	AWS	AWS is a strong option for worldwide web applications because of its extensive global infrastructure and application delivery services. EC2, Amazon CloudFront, and Amazon Route 53 can help deliver reliable and scalable applications to users in different regions.

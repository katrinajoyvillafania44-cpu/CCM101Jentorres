Questions

1. Which cloud provider has the widest selection of services?
AWS provides the largest variety of cloud services among the three major providers. It offers more than 200 services covering areas such as computing, storage, databases, networking, security, analytics, and other cloud technologies.

2. Which provider has the strongest integration with Microsoft technologies?
Microsoft Azure is the best option for integrating with Microsoft technologies. It works effectively with platforms and services such as Windows Server, Microsoft 365, Active Directory, and GitHub.

3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud is a strong platform for AI, machine learning, and Kubernetes. Google originally developed Kubernetes, and GCP provides Google Kubernetes Engine (GKE) as well as a variety of AI and machine learning services.

4. Which cloud platform would you personally select and why?
I would choose AWS because it provides a broad selection of cloud services and tools for learning, developing, and deploying applications. Since many businesses use AWS, gaining experience with the platform can also help develop practical cloud computing skills.
